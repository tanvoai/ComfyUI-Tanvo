# Changelog

## 0.1.0

- Tanvo Image, Tanvo Video and Tanvo Song nodes, with each model's own settings.
- Tanvo Photo App, Tanvo Video App and Tanvo Song App: Tanvo's ready-made apps and their preset looks.
- API key in Settings → Tanvo (or `TANVO_API_KEY`); the free model works without one.
- Two example workflows in the template browser.
